# Pilots: pre-sprint work and first sprint-day runs

Draft write-ups of small pilots run 20–23 October 2026 by Liezl, with AI coding assistance, to test ideas from the sprint's first two talks before we freeze our sprint experiment. **Runs up to 22 October are prior work** (see `docs/PRIOR_WORK.md`). **Runs on 23 October are sprint work**: results-log sections 5–10 and the Gemma and OpenRouter results in the report. They use pre-sprint code, some of it edited on 23 October; the report's prior-work disclosure lists which. Confirmatory sprint results will come from a fresh, frozen re-run.

| File | What it is |
|---|---|
| `ELI5_what_we_found.md` | Plain-language summary for non-technical readers |
| `TECHNICAL_REPORT_talk-pilots.md` | Full technical draft: motivation, links to the talks and papers, methods, results, limitations, implications for our sprint design |
| `RESULTS_2026-10-22.md` | Running results log, section by section (includes a correction in section 7) |
| `DESIGN_full_lifecycle_pipeline.md` | Design of the nine-stage grievance pipeline |
| `session-1-summary.md`, `session-2-summary.md` | Summaries of sprint talks 1 and 2 (22 Oct) |

**Not included yet:** the pilot code and raw results, and the GrieVoice v2 synthetic grievance records they run on. The records are Liezl's earlier dataset and this repo is public, so we should agree how to share them (local path, private store, or a public subset) before porting the code into `experiments/`. Paths in the write-ups refer to Liezl's local folders, so the numbers cannot yet be reproduced from this repository.
